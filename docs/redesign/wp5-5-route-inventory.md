## Migration classes

- **A — shell only:** shared chrome, typography, spacing, navigation, footer, focus, and metadata alignment.
- **B — composition cleanup:** shell migration plus removal of superseded desk/dashboard composition.
- **C — historical:** retain discoverability and URLs while clearly presenting the area as historical.
- **D — interactive shell only:** preserve behavior and specialized content; change only the containing system unless an accessibility defect requires more.
- **E — already migrated:** no redesign; compatibility changes must not regress these routes.
